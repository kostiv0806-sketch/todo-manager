# To-Do Менеджер

**Костив Никита, МИБ 301-о-02**

Простой консольный менеджер задач на Python для учёта личных дел.

## Функциональность
- 📋 Просмотр списка задач
- ➕ Добавление новых задач
- ✅ Отметка задач как выполненных
- 🗑️ **Удаление задач (новая фича)**

## Как запустить
```bash
python todo.py
